1. Connect to LiveKit

Advanced: use a ready-made token instead of key + secret

Settings stay in this browser only (localStorage). The app signs its own tokens, so no server code is needed.

2. Add another device

Open the app on the other device with one link or QR code and it is set up already.

The viewer link carries a view-only token (valid 30 days) and is safe to share with people you trust. The full device link contains your API secret, so only use it for your own devices and never post it anywhere.

No LiveKit account yet?

  1. Sign up free at cloud.livekit.io and create a project.
  2. Open Settings → Keys, create a key, and copy the API key and secret.
  3. Copy the project's WebSocket URL (starts with wss://) from the project page.
  4. Paste all three above and press Save & test connection.

Quality and watermark

The watermark is drawn into the video before it is sent, so viewers and recordings always carry it.

Always-on and low-profile

Low-profile mode covers the screen and neutralises the tab title while the cameras keep streaming. Triple-click, triple-tap or press Esc to return. Browsers always show their own camera-in-use indicator, which this app does not hide. Keep the tab open, and keep a phone's screen on.
